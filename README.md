# Projeto Redes Sociais

 Visão Geral  
Esse projeto consiste em uma página web responsiva que reúne links para as minhas redes sociais, utilizando um layout estilizado como se estivesse sendo visualizado em um dispositivo móvel (iPhone).  
Desenvolvido com foco em simplicidade, navegação visual limpa, e boas práticas de HTML e CSS.

Funcionalidades  
- Layout com estrutura de dispositivo móvel (iPhone) para apresentação dos links.  
- Links diretos para o GitHub, LinkedIn e outras redes.  
- Responsividade para diferentes tamanhos de tela.  
- Uso de HTML5 e CSS3, com atenção à semântica e usabilidade.

Tecnologias Utilizadas  
- HTML5  
- CSS3  
- (Opcional) Font Awesome para ícones sociais  

Como Executar  
1. Acesse https://valdineics.github.io/Redes-sociais/
2. Os links presentes na página vão direcionar para as minhas redes sociais.

 Diferenciais do Projeto  
- Design simples mas eficaz para portfólio de desenvolvedor.  
- Fácil de manter e expandir com novas redes, ícones ou estilos.  
- Excelente para demonstração rápida de habilidades em front-end (HTML + CSS) sem frameworks.
